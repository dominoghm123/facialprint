# FACIAL PRINT v0.0.5.3

**FACIAL PRINT** 是一个实验性的实时表情感应粒子渲染系统，它将人类面部动态映射到视听景观中。

由 **qcdomino** 创建，该项目探索了计算机视觉、生成艺术和交互式音乐的交集。

---

## 📽️ 项目摘要

该应用程序使用您的网络摄像头实时检测 468+ 个面部特征点。这些特征点被转化为密集的粒子云，响应您的动作、表情和情感。同时，一个定制的 Web Audio 引擎会生成同步的配乐，根据您的“温暖度”（微笑）、“活跃度”（动作）和“开放度”（嘴部状态）实时改变旋律、节奏和纹理。

---

## 🛠️ 技术实现

### 1. 面部感知 (MediaPipe Face Mesh)
- **特征点检测**：使用 Google 的 MediaPipe 跟踪高保真面部几何形状。
- **归一化**：为了确保稳定性（无论用户距离摄像头远近），系统使用参考向量（例如面部的 3D 宽度）对距离进行归一化。
- **表情推导**：
    - `exprSmile`：通过嘴角相对于面部宽度的水平拉伸计算得出。
    - `mouthOpen`：通过上下唇之间的垂直间隙测量得出。
    - `isSleeping`：使用 **眼动比例 (EAR)** 进行检测；如果眼睛闭合超过 2 秒，系统进入“睡眠”状态，降低音乐 BPM。
- **姿态估计**：跟踪俯仰 (Pitch)、偏航 (Yaw) 和翻滚 (Roll) 以驱动“运动幅度”，从而影响音乐的复杂度和失真度。

### 2. 生成式视觉 (Canvas 2D 粒子系统)
- **点位缓存 (Dot Cache)**：为了保持高性能，粒子并非每帧生成。相反，系统在特征点周围构建静态“点位缓存”，并根据当前面部网格的形变更新其位置。
- **风格与混合**：
    - 五种独特主题（**INK, DUST, AMBER, AURORA, VELVET**）定义了粒子行为（尾迹长度、颜色映射、密度）。
    - **渐进式风格切换**：切换风格时会触发 HSLA 属性的线性插值，在不同视觉氛围间创造平滑过渡。
- **优化裁剪**：使用自定义的 `clipOval` 函数确保粒子仅在面部的自然轮廓内渲染，创造出“全息面具”效果。

### 3. 视听合成 (Web Audio API)
- **预调度器 (Look-ahead Scheduler)**：一种高精度的音序器模式，通过稍微提前调度音频事件来确保完美同步，克服了传统 `setTimeout` 的抖动问题。
- **表情到音乐的映射**：
    - **和谐模式**：表情触发音乐调式的切换（Dorian → Mixolydian → Major → Lydian）。微笑程度与“亮度”直接相关。
    - **动态 BPM**：头部运动速度（运动幅度）动态将 BPM 从 80 提升至 116。
    - **颗粒化音效**：使用正弦波和过滤白噪音构建的简洁而动人的点击与快门声。
- **波形可视化**：顶部栏的像素化粒子分析器提供主增益输出的实时反馈。

### 4. 电影级拍摄系统
- **三连拍**：按照用户选定的不同风格进行 3 帧序列捕捉，并带有倒计时过程。
- **视频录制**：利用 `MediaRecorder API` 直接从 Canvas 录制 15 秒高清视频片段。
- **胶片处理器**：一个定制的组合引擎，将捕捉到的画面包装在风格化的电影胶片中，包含齿孔、边缘标记和可自定义的影调。

## 🚀 快速开始

1. 在任何现代浏览器（Chrome/Edge/Safari）中打开 `facial-print-v0.0.5.3.html`。
2. 允许相机访问权限。
3. 点击 **SOUND [OFF]** 按钮初始化音频。
4. **交互**：
    - **微笑**：调亮音乐和视觉色彩。
    - **移动**：增加节奏和视觉能量。
    - **歪头**：调制并扭曲声音纹理。
    - **捕捉**：使用右侧按钮将您的“面部指纹”保存为照片或视频。
